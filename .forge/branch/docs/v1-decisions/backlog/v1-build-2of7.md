# v1 구축 2/7 — 계정·관리자

> 범위만 적은 초안이다. 실행 전에 fg-ask로 슬라이스·완료 기준·TDD 여부를 다시 다듬는다(1번 결과로 생긴 실제 구조에 맞추기 위해). 실행 주체: Paseo 역할 팀.

## 목표 / 범위 밖
- 목표: 회원가입 신청 → 관리자 승인 → 로그인 흐름과 관리자 기능(승인·정지·비밀번호 초기화·회원 삭제)을 만든다. 첫 관리자는 환경변수·시드로 생성.
- 범위 밖: 사용량 조회(5번에서 호출 기록과 함께), 메일 발송
