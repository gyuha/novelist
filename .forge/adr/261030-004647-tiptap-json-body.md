# 챕터 본문은 TipTap(ProseMirror) JSON으로 저장한다

웹소설 본문은 서식이 거의 필요 없는데도 일반 텍스트나 마크다운이 아닌 TipTap 리치 텍스트(문단·강조·장면 전환선만 허용)를 쓰고, 본문을 ProseMirror JSON으로 저장한다. 본문 주석을 ProseMirror 마크로 걸면 편집해도 주석이 텍스트를 자동으로 따라가지만, 텍스트 형식에서는 문자 오프셋을 직접 재계산해야 하기 때문이다. 주석이 걸린 텍스트가 통째로 지워지면 주석은 삭제하지 않고 '위치 잃은 주석'으로 보존한다. 대가로 txt·마크다운 내보내기와 AI 컨텍스트 입력에는 JSON → 순수 텍스트 변환이 필요하다.
