# novelist 디자인 명세

## 적용 범위와 근거

S5의 구현 전달 문서. 기준은 `docs/v1-decisions.md`, `.forge/CONTEXT.md`, 기반 계획의 S5다. 모든 데이터는 로그인한 회원 자신의 데이터다. 관리자는 회원 관리와 사용량만 보며 다른 회원의 소설 본문으로 이동하는 링크를 제공하지 않는다. 공개 발행·공유·결제·메일 발송·버전 비교는 없다. 화면 경로는 프런트엔드 구현을 위한 제안이며 API 계약이 아니다.

## 디자인 원칙

- **본문이 중심이다.** 집필은 조작 중심(Operate), 리더는 읽기 중심(Read)이다. 소설 제목과 실제 문장을 먼저 보여 주고 통계나 장식으로 주의를 빼앗지 않는다.
- **서로 다른 글의 상태를 구별한다.** 본문, 아직 수락하지 않은 AI 초안, 저장된 스냅샷을 제목·위치·상태 문구로 구별한다. 색에만 의존하지 않는다.
- **긴 한국어 문장을 편안하게 읽는다.** UI는 고딕, 본문은 명조 기본값을 쓴다. 강제 양쪽 정렬, 자간 압축, 한 글자씩 등장하는 애니메이션을 쓰지 않는다.
- **낮과 밤의 집필을 지원한다.** 밝은 모드는 중성 바탕과 흰 본문, 어두운 모드는 녹색 기가 약한 어두운 바탕을 쓴다. 강조색은 초록 계열 하나이며 위험·주석만 별도 의미색을 쓴다.
- **상태와 복구 방법이 같은 곳에 있다.** 저장 실패는 저장 버튼 옆에, 생성 실패는 초안 영역에 표시한다. 다시 시도할 때 입력을 보존한다.
- **모바일의 목적을 분명히 한다.** 읽기와 메모 작성·편집·삭제를 완전하게 지원한다. 본문 집필·AI·삽화 생성·관리 조작은 데스크톱에서 수행한다.

## 토큰과 공통 컴포넌트

### 불러오기와 테마

`apps/web/src/app/layout.tsx`에서 `import "../styles/tokens.css";`를 전역 CSS보다 먼저 한 번 불러온다. 파일은 변수와 테마·동작 환경별 재정의만 제공하며 reset이나 컴포넌트 스타일은 프런트엔드가 작성한다. 이후 CSS는 `var(--color-text)`처럼 참조한다.

`html`의 `data-theme="light" | "dark"`로 명시 선택한다. 시스템 선택은 속성을 제거한다. 설정 선택지는 시스템·밝게·어둡게이며 회원 브라우저에 저장하고 최초 페인트 전에 반영한다. 서버 렌더와 충돌하지 않도록 초기화한다. 폰트는 네트워크 다운로드를 전제하지 않으며 로컬 폴백만으로 동작한다. 폰트 파일을 추가한다면 별도 라이선스 확인과 self-host를 거친다.

### 시각 규칙

| 용도 | 토큰 / 구현 규칙 |
| --- | --- |
| 페이지·본문·보조 영역 | `--color-canvas`, `--color-surface`, `--color-surface-muted` |
| 제목·본문·보조 설명 | `--color-text`, `--color-text-secondary`; 흐린 텍스트도 명도 대비 유지 |
| 구분선·입력 테두리 | `--color-border`; 필수 입력 경계는 `--color-border-strong` |

| 상태 | `--color-success`, `--color-warning`, `--color-danger`와 각각의 `-soft`; 아이콘·문구 동반 |
| 선택·주석 | `--color-selection` / `--color-selection-text`, `--color-annotation` / `--color-annotation-text` |
| 모서리·깊이 | 입력·버튼 `--radius-control`, 패널 `--radius-panel`, 대화상자 `--radius-dialog`; 평면 영역은 구분선, 떠 있는 영역만 `--shadow-popover` 또는 `--shadow-dialog` |
| 간격 | 밀접한 라벨·입력은 `--space-2`, 항목 내부 `--space-3`·`--space-4`, 그룹 간 `--space-6`, 페이지 구획 `--space-8`·`--space-12` |

| 포커스 | `--focus-width` 실선 `--color-focus`, `--focus-offset`; `:focus-visible` 표시, 선택·캐럿·스크롤바도 의미색 사용 |
| 겹침 | 일반 `--z-base`, 고정 `--z-sticky`, 메뉴 `--z-popover`, 비모달 패널 `--z-drawer`, 모달 배경 `--z-overlay`, 모달 `--z-dialog`, 알림 `--z-toast` |
| 모션 | hover `--motion-fast`, 패널 `--motion-normal`, 대화상자 `--motion-slow`와 `--ease-out`; 상태를 숨기지 않고 reduced-motion에서는 시간 토큰을 사용해 즉시 전환 |

UI는 `--font-ui`, `--font-size-ui`, `--line-height-ui`; 보조 설명은 `--font-size-small`, 날짜는 `--font-size-caption`을 사용한다. 제목은 `--font-size-title`·`--font-size-heading`, `--line-height-heading`, `--font-weight-emphasis`. 사용량 숫자는 같은 UI 폰트와 `font-variant-numeric: tabular-nums`로 정렬한다.

본문은 `--font-prose`, `--font-size-prose`, `--line-height-prose`, `--letter-spacing-prose`, 폭 `--measure-prose`, 문단 간격 `--paragraph-gap`을 쓴다. 한국어 기준 한 줄 약 30~34글자를 목표로 하므로 라틴 문자 `ch` 대신 `em` 기반 폭을 사용한다. `word-break: keep-all; overflow-wrap: anywhere; white-space: pre-wrap`으로 한국어 어절을 우선 보존하고 긴 URL은 줄바꿈한다. 왼쪽 정렬, 문단 첫 줄 강제 들여쓰기 없음. 에디터와 리더의 본문 렌더 규칙은 같다. 장면 전환선은 장식 아이콘 없이 중앙의 짧은 구분선과 `--space-8` 상하 여백으로 표현한다.

### 접근성과 상태 공통 계약

본문으로 건너뛰기 링크, `header/nav/main/aside`, 한 화면의 주 제목 하나, 입력의 가시적 라벨을 제공한다. 모든 아이콘 버튼은 접근 가능한 이름과 툴팁을 갖는다. 현재 메뉴는 `aria-current`, 탭은 방향키 이동과 연결 패널을 갖춘다. 일반 텍스트 대비 목표는 4.5:1, 큰 글자와 조작 경계는 3:1이다. `--color-border`는 장식 구분선에만 쓸 수 있다.

목록 로딩은 기존 행을 지우지 않고 해당 영역 `aria-busy`와 정적 자리표시를 쓴다. 최초 빈 상태에는 원인 설명과 다음 행동 하나를 둔다. 필터 결과 없음은 데이터 없음과 구분하고 필터 초기화를 제공한다. 오류는 `role="alert"`와 재시도, 성공·저장은 `role="status"`로 알린다. 스트리밍 본문 전체를 live region으로 만들지 않고 시작·완료·오류만 알린다. 화면별로 해당하지 않는 스트리밍 상태는 아래에 명시한다.

모달은 위험 행동·스냅샷 복원에만 사용하며 제목, 취소, 명확한 실행 버튼을 갖춘다. 열 때 포커스를 이동하고 배경을 비활성화하며 닫으면 호출자로 돌린다. 목록에서 생성·편집은 가능한 한 인라인 또는 보조 패널에서 한다. 저장 실패·미저장 내용은 화면 전환으로 조용히 버리지 않는다.

## 앱 셸 명세

### 영역과 탐색

헤더 높이는 `--header-height`, 위에 고정한다. 왼쪽은 `novelist` 홈 링크, 중앙은 소설·챕터 breadcrumb(중간 항목 말줄임), 오른쪽은 저장 상태(에디터), 테마, 계정 메뉴다. 계정 메뉴는 이메일·로그아웃, 관리자에게만 관리자 이동을 제공한다. 승인 전 화면은 별도의 간소 헤더를 사용한다.

일반 데스크톱은 `[왼쪽 탐색 | main]`. 왼쪽 폭 `--nav-width`, 헤더 아래에 고정하고 내부 스크롤한다. 메뉴는 **소설**, **메모**이며 최근 소설 이름을 보조 목록으로 둘 수 있다. 별도 회원별 공간 선택기는 만들지 않는다. 메인 폭은 `--page-max-width`, 좌우 `--page-gutter`, 상하 `--space-8`. 화면 제목 행 아래 실제 목록·본문을 배치한다. 일반 목록은 페이지 자체가 스크롤한다.

소설 내부에서는 breadcrumb로 소설 목록으로 돌아간다. 소설 하위 탐색은 **챕터 / 메모 / 캐릭터 / 삽화**, 주석은 챕터에서 진입한다. 메모·캐릭터는 에디터 패널과 동일 데이터를 쓰는 소설 하위 화면이다. 자유 메모는 전역 메모에서 접근한다.

에디터는 전역 왼쪽 탐색을 **챕터 탐색**으로 교체한다. `[챕터 탐색 | 본문 | 보조 패널]`. 본문 영역 상단의 도구 행, 가운데 본문, 하단의 저장 상태를 구분한다. 본문·챕터 탐색·패널은 각각 독립 스크롤하되 창 전체에 중첩 가로 스크롤이 생기지 않도록 모든 grid 자식에 `min-width: 0`을 준다. 높이는 `100dvh`에서 헤더를 제외한다. AI 초안이 늘어나도 본문 스크롤 위치를 밀어내지 않는다.

### 반응형 기준

CSS 미디어 조건에는 변수 사용이 불가능하다. 구현에서 아래 두 값만 리터럴로 사용하고 다른 길이는 토큰을 사용한다.

| 구간 | 기준 / 배치 |
| --- | --- |
| 모바일 | `width < 48rem` (`--breakpoint-desktop`): 단일 열, `--page-gutter`의 모바일 재정의. 헤더 메뉴에서 탐색 서랍 열기. 하단 고정 메뉴는 두지 않는다. 읽기·메모는 전체 기능 지원. |
| 데스크톱 | `48rem <= width < 75rem`: 일반 탐색은 버튼으로 여닫는 모달 서랍. 에디터는 본문 한 열과 요청 시 여는 모달 보조 패널(`--inspector-width`, viewport 안으로 제한). 챕터 탐색도 서랍으로 전환해 본문 최소 폭을 보존한다. |
| 넓은 데스크톱 | `width >= 75rem` (`--breakpoint-wide`): 일반 탐색 상시 노출. 에디터는 `--chapter-nav-width / minmax(0, 1fr) / --inspector-width`; 보조 패널 닫기 가능. 본문은 내부 중앙 정렬, 폭 `min(100%, var(--measure-prose))`. |

서랍의 배경은 `--color-overlay`; 모달로 열리는 서랍은 `--z-dialog`와 포커스 트랩을 사용한다. 상시 노출된 패널은 `--z-base`이며 포커스를 가두지 않는다. 모바일에서 에디터 URL을 열면 같은 챕터의 읽기 본문과 메모 진입, “본문 편집과 AI는 데스크톱에서 사용할 수 있습니다”를 보여 준다. 화면을 막는 전체 페이지 경고는 쓰지 않는다. 확대·가상 키보드·safe-area를 고려하고 주요 버튼은 가로 넘침 없이 줄바꿈한다.

## 로그인·가입

경로 제안: `/login`, `/signup`. 셸: 간소 헤더 → 중앙 `--auth-max-width` 폼 → “가입 후 관리자 승인이 필요합니다” 안내. 제목, 이메일, 비밀번호, 주 버튼, 로그인/가입 전환 순서다. 가입은 비밀번호 확인을 추가한다. 비밀번호 보기 버튼은 값을 유지한다. 자동완성은 이메일·현재/새 비밀번호에 맞춘다. 비밀번호 규칙은 shared 스키마에서 가져와 입력 아래 설명하며 이 문서에서 임의 길이를 정하지 않는다.

로그인 성공은 소설 목록, 대기 계정은 승인 대기 화면으로 보낸다. 비밀번호 분실 안내는 “관리자에게 비밀번호 초기화를 요청해 주세요”; 메일 재설정 버튼은 없다. 정지 상태는 로그인 폼 위 고정 안내로 표시한다.

상태: 빈 폼은 예시 대신 라벨·도움말, 전송 중 버튼 “로그인 중…”/“가입 신청 중…” 및 중복 제출 방지, 오류는 입력 옆 필드 오류와 폼 상단 인증 오류. 스트리밍 없음. 모바일은 동일 폼의 단일 열이며 화면 확대 없이 입력 가능하다.

## 승인 대기

경로 제안: `/pending`. 간소 헤더 → `--auth-max-width` 안내. “가입 승인을 기다리고 있습니다”, 신청 이메일, “관리자가 승인하면 이용할 수 있습니다”, **승인 상태 확인**, 로그아웃을 순서대로 둔다. 승인 완료 시 소설 목록으로 이동한다. 승인 예상 시간이나 메일 알림을 약속하지 않는다.

상태: 계정 정보 로딩은 정적 자리표시, 새로 확인 중에는 버튼만 busy, 조회 오류는 “상태를 확인하지 못했습니다”와 재시도. 빈 데이터는 로그인 세션 확인 후 로그인으로 안내한다. 정지 전환은 “이용이 정지되었습니다. 관리자에게 문의해 주세요”로 대체. 스트리밍 없음. 모바일은 동일 단일 열이다.

## 관리자

경로 제안: `/admin`. 셸 main의 제목 “회원 관리” → **가입 대기 / 회원 / AI 사용량** 탭. 대기 목록은 이메일·신청일·승인 버튼, 회원 목록은 이메일·상태·가입일·행 메뉴다. 검색과 상태 필터를 제목 아래 둔다. 행 메뉴는 정지/정지 해제, 비밀번호 초기화, 회원 삭제. 초기화 결과의 임시 비밀번호가 제공된다면 완료 패널에서 한 번 보여 주고 복사·닫기를 제공하며 목록·토스트에 노출하지 않는다. 실제 초기화 입력 방식은 API 계약에 따른다.

삭제는 확인 모달에서 대상 이메일과 “소설·챕터·메모·삽화 파일이 즉시 영구 삭제됩니다”를 표시한다. 이메일 재입력 후 **회원 영구 삭제**가 활성화된다. 취소가 기본 포커스다. 정지는 별도 설명과 **회원 정지** 확인을 제공한다. 실패 시 모달을 유지한다.

사용량 탭은 기간·회원 필터 → 텍스트/이미지 호출 수와 제공되는 토큰·비용 필드 → 날짜·회원·작업 종류·성공/실패·사용량 표. 계약에 없는 비용 추정·회원별 한도 설정은 만들지 않는다.

상태: 대기 없음은 “대기 중인 가입 신청이 없습니다”, 로딩은 행 자리표시, 행 작업 중에는 해당 행만 잠금, 조회/작업 오류는 해당 영역 재시도. 권한 없음은 관리자 데이터를 먼저 렌더하지 않고 접근 불가 안내. 스트리밍 없음. 모바일은 세로 행으로 조회만 제공하고 관리 조작은 데스크톱 안내로 대체한다.

## 소설 목록

경로 제안: `/novels`. 제목 “내 소설” + **새 소설** → 검색 → 목록. 각 행은 소설 제목(주 링크), 최근 수정일, 챕터 수, 더보기다. 표지 이미지나 미확인 통계를 의무 항목으로 두지 않는다. 최근 수정 순을 기본으로 하며 긴 제목은 두 줄까지 허용한다. 새 소설은 목록 위 인라인 입력에서 제목·선택 설명·만들기/취소로 작성한다. 제목 변경·삭제는 더보기에서 진입하며 삭제 확인에 하위 데이터 범위를 알린다.

상태: 소설 없음은 “첫 소설을 만들어 보세요”와 새 소설, 검색 결과 없음은 검색 초기화. 로딩은 행 자리표시, 오류는 목록 상단 재시도. 스트리밍 없음. 모바일은 전체 행을 챕터 목록 링크로 쓰고 새 소설·이름 변경 등 집필 관리 행동은 숨긴다. 메모와 읽기로 진입하는 탐색은 유지한다.

### 메모·캐릭터 보조 화면

전역 `/memos`는 범위 필터 **전체 / 자유 / 소설 / 챕터**와 소설·챕터 선택, 검색, 새 메모를 갖춘다. 데스크톱은 `[목록 | 메모 편집]`, 모바일은 목록→편집의 두 단계다. 메모는 제목·내용·소속·AI 참고 체크·저장·삭제로 구성한다. 새 메모 기본 소속은 진입한 소설/챕터, 전역에서는 자유다. AI 참고 기본값은 꺼짐. 자유 메모도 표시할 수 있으나 특정 소설 요청에 포함되는 범위는 컨텍스트 API 계약에 따르며 UI는 실제 전달 범위를 명시한다. 빈 목록·저장 중·저장 실패·삭제 확인은 동일 규칙이다. 스트리밍 없음.

소설 캐릭터 화면은 목록과 상세 폼(이름·외형 묘사·참조 이미지 업로드/삭제). 파일 제한은 API 검증 계약으로 안내한다. 이미지 로딩·업로드 중·실패·참조 이미지 없음 상태를 별도로 둔다. 데스크톱에서 관리하고 모바일은 조회한다.

## 챕터 목록

경로 제안: `/novels/:novelId`. 제목·설명 → 소설 하위 탐색 → **새 챕터 / 내보내기 / 리더로 읽기** → 순서 있는 챕터 목록. 각 행은 순번·챕터 제목·최근 저장일·행 메뉴. 제목은 에디터로, 별도 읽기 버튼은 리더로 진입한다. 새 챕터는 제목 입력 후 생성하여 에디터로 이동한다. 정렬 변경을 제공한다면 드래그만 강요하지 않고 위로/아래로 이동도 제공한다.

내보내기 메뉴는 **소설 전체 TXT / 소설 전체 Markdown**이다. 다운로드 중 상태와 실패 재시도를 메뉴 인접 위치에 표시한다. 스냅샷은 여기서 비교하지 않고 챕터 에디터의 이력에서 복원한다.

상태: 챕터 없음은 새 챕터 안내, 로딩은 행 자리표시, 조회·생성 오류는 목록/생성 폼에 보존, 스트리밍 없음. 모바일 제목 링크는 리더로, 메모는 하위 탐색에서 완전 지원한다. 생성·순서 변경은 데스크톱에서 제공한다. 내보내기는 모바일 브라우저 다운로드가 가능하면 유지한다.

## 에디터

경로 제안: `/novels/:novelId/chapters/:chapterId/edit`. 넓은 화면 와이어프레임:

```text
[novelist] [소설 > 챕터]                         [저장 상태] [계정]
[챕터 목록] | [챕터 제목] [저장] [스냅샷] [읽기] | [AI 초안 | 메모 | 캐릭터]
[현재 챕터] | [강조 / 장면 전환 / 주석 / 삽화]   | [선택 탭의 내용]
[다른 챕터] |                                  |
           |          집필 본문                 |
           |                                  |
```

본문은 TipTap이며 사용자에게 노출하는 서식은 문단·강조·장면 전환선뿐이다. 강조는 굵게로 일관되게 표현한다. 제목 서식·색상·표·목록·본문 이미지 삽입은 제공하지 않는다. 주석은 위치를 추적하는 내부 mark다. 붙여넣기는 허용된 문단/강조만 유지하도록 정규화한다. 선택 텍스트가 없으면 주석·다시쓰기·장면 삽화 행동 옆에 선택 필요 안내를 제공한다.

저장은 명시적 **저장**과 Cmd/Ctrl+S를 기준으로 한다. 상태는 “변경 없음 / 저장하지 않은 변경 / 저장 중… / 저장됨 [시각] / 저장 실패 · 다시 시도”다. 저장 요청 완료 전 성공으로 바꾸지 않는다. 챕터 저장 후 요약 생성은 별도 “챕터 요약 갱신 중…”으로 표시하며 요약 실패가 본문 저장 실패처럼 보이지 않게 한다. 미저장 본문·미수락 초안을 두고 챕터 이동/닫기를 요청하면 저장·폐기·계속 편집 선택을 제공한다.

### AI 초안 패널

탭 기본값은 AI 초안이며 패널은 `--color-surface-muted`, 초안 자체는 `--color-surface`. 상단 **이어쓰기 / 다시쓰기 / 다음 전개 / 챕터 요약** → 지시 입력(선택) → 컨텍스트 개요(참조할 메모와 캐릭터, 요약 상태) → **생성** → AI 초안 → **수락 / 거절 / 재생성** 순서다. “참고 표시가 없는 메모는 사용하지 않습니다”를 표시한다. 캐릭터는 소설 전체 항목이 포함됨을 알린다.

이어쓰기는 생성 시작 시점 커서 위치, 다시쓰기는 생성 시작 시 선택 범위를 대상 앵커로 표시한다. 다음 전개는 본문을 바로 바꾸지 않는 아이디어 초안이며 수락 시 확인된 삽입 위치에 반영한다. 요약은 저장 시 자동 생성된 챕터 요약을 보여 주며 본문 수락 버튼을 두지 않는다. 요약이 오래되었으면 저장 후 갱신 안내를 제공한다.

준비 중은 “참고 자료를 준비하고 있습니다”, 스트리밍 중은 “AI 초안 작성 중…”·**중단**만 제공한다. 텍스트는 청크 도착대로 표시하되 사용자가 위로 스크롤하면 자동 따라가기를 멈추고 **최신 위치**를 제공한다. 수락·재생성은 완성 전 비활성화한다. 중단·연결 오류의 부분 초안은 유지하지만 본문에 수락하지 못하며 **다시 생성**·**버리기**를 제공한다. 완료 시 세 행동 활성화. 재생성은 기존 초안을 요청 성공 전까지 보존하며 교체 중임을 알린다.

초안이 열린 동안 대상 본문은 읽기 전용으로 잠가 앵커 오적용을 막는다. 메모·캐릭터 수정은 가능하지만 기존 초안에는 반영되지 않으며 재생성이 필요하다고 안내한다. **수락**은 직전 스냅샷 저장 성공 → 본문 반영·저장 성공 확인 → 완료 순서다. 실패 시 초안을 유지하고 중복 삽입 없이 재시도한다. **거절**은 본문을 바꾸지 않고 초안을 비운다. 초안은 본문 저장 상태와 구별한다.

### 메모·캐릭터 패널

메모 탭은 현재 챕터/소설/자유 범위 선택 → 목록 → 선택 메모 인라인 편집 → AI 참고 체크와 저장. 별도 전체 메모 화면으로 나가는 링크를 둔다. 새 메모를 쓸 때 본문 선택을 요구하지 않는다. 캐릭터 탭은 이름·참조 이미지 썸네일 목록 → 이름·외형 묘사·참조 이미지 폼. 빈 상태에서 “캐릭터 추가”, 업로드 실패는 파일 선택을 유지하고 재시도한다. 어느 패널도 본문을 덮거나 저장 상태를 가리지 않는다.

### 스냅샷·오류·모바일

스냅샷 버튼은 측면 이력 패널(현재 AI 탭과 대체)에서 수동 저장·목록을 연다. 행은 저장 시각과 자동/수동 구분. 선택하면 읽기 전용 전체 본문 미리보기와 **이 스냅샷으로 복원**. 복원 확인에서 현재 변경 대체를 알린다. 미저장 변경이 있으면 저장 또는 취소 후 진행한다. 버전 비교 UI는 없다. 복원 실패는 현재 본문을 유지한다.

본문 없음은 빈 문단과 “첫 문장을 입력하세요”, 로딩은 본문 편집 잠금과 자리표시, 조회 오류는 재시도, 저장 오류는 입력 보존과 경고. 모바일은 리더 본문으로 대체하고 메모 탭만 단일 열 화면에서 편집한다. 모바일에 비활성 도구막대를 나열하지 않는다.

## 주석

경로 제안: 챕터 에디터의 주석 패널 또는 `/novels/:novelId/chapters/:chapterId/annotations`. 데스크톱 `[읽기 본문 | 주석 목록/상세]`, 상단 챕터 제목과 **에디터로 돌아가기**. 필터 **전체 / 본문에 연결됨 / 위치 잃음**. 행은 인용 텍스트·주석 내용·수정일. 본문 강조와 목록 선택을 함께 표시하고 선택 시 해당 문장으로 이동한다. 새 주석은 에디터 본문 선택 → **주석 추가** → 내용 입력·저장이다.

위치 잃은 주석은 별도 상태 라벨, 저장된 인용문이 있으면 이를 보여 주고 “연결된 본문이 삭제되었습니다”를 표시한다. 임의의 비슷한 문장에 자동 재연결하지 않는다. 내용 편집·삭제는 가능하다. 주석을 AI 참고 메모로 자동 취급하지 않는다.

상태: 없음은 본문 선택 방법 안내, 로딩은 주석 목록 자리표시, 저장 오류는 입력 유지, 조회 오류는 재시도. 스트리밍 없음. 모바일은 읽기 전용 본문과 주석 목록을 전환하며 선택 시 인용 위치로 이동한다. 위치 잃은 주석은 그대로 조회하고 새 주석·본문 연결 편집은 데스크톱으로 안내한다.

## 삽화

경로 제안: `/novels/:novelId/illustrations`. 제목·소설 하위 탐색 → **삽화 만들기** → 생성 패널 → 저장된 삽화 격자. 이미지는 원본 비율을 유지하며 썸네일 목록에서 선택하면 확대 이미지·프롬프트·등장 캐릭터·생성일 상세를 보여 준다. 생성 패널은 데스크톱 `[입력 | 미리보기/상태]` 두 영역이다.

생성 순서: **장면 본문 선택/붙여넣기** 또는 **프롬프트 직접 입력** → **프롬프트 초안 만들기** → 편집 가능한 프롬프트 → 자동 제안된 캐릭터 체크 목록·참조 이미지 미리보기 → **삽화 생성**. 장면 선택으로 에디터에서 진입하면 선택 본문과 소설을 유지한다. 회원이 자동 선택을 바꿀 수 있고, 참조 이미지가 없는 캐릭터는 “참조 이미지 없음 · 외형 일관성이 낮아질 수 있습니다”와 캐릭터 편집 링크를 제공한다. 생성 품질을 보장하는 문구는 쓰지 않는다.

상태: 삽화 없음은 생성 CTA, 프롬프트 준비 중은 입력을 보존하고 busy, 텍스트 초안이 스트리밍이면 해당 입력 옆 진행 상태와 중단·오류 복구를 제공하고 완료 전 이미지 생성을 막는다. 이미지 생성 중은 크기를 가진 정적 미리보기와 “삽화를 생성하고 있습니다”; 가짜 퍼센트 없음. 완료 후 저장된 이미지를 목록에 추가한다. 실패는 프롬프트·캐릭터 선택을 유지하고 **다시 생성**. 이미지 로딩 실패는 **이미지 다시 불러오기**와 메타데이터를 유지한다. 모바일은 단일 열 갤러리·확대 조회만 제공하며 생성은 데스크톱에서 수행한다.

## 리더 뷰

경로 제안: `/novels/:novelId/chapters/:chapterId/read`. 일반 좌측 탐색을 없애고 축소 헤더(소설로 돌아가기·소설 제목·목차·읽기 설정)를 사용한다. 중앙 `--measure-prose` 본문 → 이전/다음 챕터 → **이 챕터 메모**. 챕터 제목은 본문 위 `--space-12` 여백을 두고 표시한다. 본인만 읽을 수 있으며 공유·발행·독자 반응 도구는 없다. 데스크톱에서만 **편집으로 돌아가기**를 제공한다.

읽기 설정은 본문 글꼴 고딕/명조(`--font-ui`/`--font-prose`), 크기 기본/크게(`--font-size-prose`/`--font-size-prose-large`), 폭 기본/좁게(`--measure-prose`/`--measure-prose-narrow`), 테마를 제공한다. 브라우저 확대를 막지 않는다. 목차는 데스크톱 popover, 모바일 모달 서랍으로 열고 현재 챕터·이전/다음을 표시한다. 주석은 기본 강조를 숨기고 “주석 표시”로 조회 가능하다.

상태: 빈 본문은 “아직 작성된 본문이 없습니다”와 챕터 목록, 로딩은 본문 영역 자리표시, 조회 오류는 재시도. 스트리밍 없음: 저장된 본문만 읽는다. 모바일은 같은 본문을 화면 폭과 `--page-gutter`로 제한하며 가로 스크롤이 없다. 메모는 별도 전체 화면으로 열어 내용·AI 참고·저장·삭제를 완전 지원하고 돌아오면 읽던 위치를 복원한다. 소설/챕터 이동은 저장된 데이터에만 의존한다.

## 구현 전달 및 검증 기준

프런트엔드는 토큰을 수정하지 않고 필요한 추가 토큰을 디자인 역할에 요청한다. API 필드·경로·비밀번호 규칙·이미지 제한은 shared 계약이 우선이다. 위 화면 경로, 요약/다음 전개 수락 방식, 모바일 관리 조회 정책은 제품 문서에 세부가 없어 이 문서에서 선택한 UX 가정이다. 에디터 자동 저장은 필수로 가정하지 않았으며 명시 저장을 기준으로 한다.

구현 시 밝게·어둡게·시스템, 모바일·데스크톱·넓은 데스크톱, 키보드 전용, reduced-motion에서 검증한다. 특히 긴 한국어 제목·장문·긴 URL, 초안 스트리밍 중 스크롤, 저장 실패 후 이동, 위치 잃은 주석, 회원 영구 삭제, 빈 소설→첫 챕터→집필→초안 수락→스냅샷 복원→리더→내보내기를 확인한다. 이 산출물은 CSS 변수와 와이어프레임 명세이며 실행 가능한 앱이 없어 실제 렌더·동작 검증은 프런트엔드 구현 후 수행한다.
